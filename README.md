# Proyecto Colaboración en Python

Este proyecto se hizo como una práctica de programación en Python utilizando Git y GitHub.

El objetivo es organizar diferentes funciones separados y utilizando un archivo principal para ejecutar y probar cada una de ellas.

## ¿Cómo ejecutar el proyecto?

Para ejecutar el programa principal se debe abrir una ventana o por decirlo así una terminal dentro de la carpeta del proyecto y escribir:

```bash
python main.py

## Descripción por Módulos de Proyectos

### operaciones.py
Contiene funciones para realizar operaciones matemáticas básicas como suma, resta, multiplicación y división.

### cuento.py
Contiene una función que imprime un cuento corto como parte de la práctica de programación.

### utilidades.py
Contiene funciones auxiliares para comprobar si un número es par o impar y calcular el promedio de una lista de notas.

### main.py
Es el archivo principal del proyecto. Importa las funciones de los diferentes módulos y permite probar sus funcionalidades.
