# Proyecto Colaboraci-n en Python

Este proyecto se hizo como una práctica de programación en Python utilizando Git y GitHub.

El objetivo es organizar diferentes funciones separados y utilizando un archivo principal para ejecutar y probar cada una de ellas.

## ¿Cómo ejecutar el proyecto?

Para ejecutar el programa principal se debe abrir una ventana o decirlo así una terminal dentro de la carpeta del proyecto y escribir:

```bash
python main.py
